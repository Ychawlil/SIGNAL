# SIGNAL Universe：项目审查与实施记录

## Phase 1：审查结果

- 技术：Next.js 16.4.2、React/React DOM 19.3.0、TypeScript 5、Tailwind 4、Node SQLite。
- 路由：src/app App Router；首页是带手动更新、阅读进度的每日简报。探索、研究、分析、趋势、主题、研究库、设置和历史简报均仍有用途。
- 数据：.data/signal.db 及 WAL/SHM 正在使用；服务端 SQLite、RSS/arXiv/GitHub/Hacker News 采集、任务锁和评分独立于页面。禁止删除这些数据与迁移。
- 配置：next.config.ts 保留现有 Turbopack CSS loader；端口 2026。scripts/launch.ps1 与桌面启动器依赖 package.json；instrumentation.ts 启动可选调度器。无须改变部署方式。
- 环境：只审查 .env.example 和服务端 env.ts；不读取或更改 .env.local 密钥。
- 已有图形依赖：无 Three.js、R3F、Drei 或 Motion。新增 Three.js 及对应 TypeScript 类型即可实现此导航，不额外引入动画和 React 场景库。
- 当前有大量先前工作的未提交/已暂存改动；不会回滚、重置或重新暂存它们。

## 实施顺序

1. 配置与只读统计 API；三维场景懒加载；场景与相机状态独立。
2. 六颗程序化微缩星球；拖动、缩放、聚焦、进入过渡；键盘与普通链接并存。
3. 柔和光照、低多边形地貌、低密度星空、响应式 HTML 面板。
4. 接入数据库真实总量、24 小时内发布数量、最后采集/分析时间；未读由已有浏览器阅读状态计算。脉冲只依据真实 24 小时新增，可关闭。
5. 引用审查后清理确定无用的默认 SVG、重复导航配置和未使用依赖；保留仍使用的旧简报组件、背景库、生成脚本、全部数据与测试。
6. TypeScript、Lint、测试、生产构建、接口和三维交互回归。

参考：Three.js 官方 OrbitControls 文档 https://threejs.org/docs/pages/OrbitControls.html；WebGLRenderer 文档 https://threejs.org/docs/pages/WebGLRenderer.html。只借鉴 Besiege 的微缩模型语言，不使用其资产。

## Phase 2–4：实现

- src/components/universe/universe-home.tsx：HTML 覆盖层、路由选择、偏好、搜索与统计；next/dynamic 仅在首页客户端加载三维模块。
- universe-canvas.tsx：WebGLRenderer、OrbitControls、射线拾取、触屏缩放、键盘选中、暂停/减少动态效果、上下文丢失降级、尺寸观察与完整卸载清理。
- planet-model.ts：六种原创程序化地貌，共享材质、限制细分；支持通过配置 modelUrl 可选加载/归一化 GLB，并保留失败时的程序模型。
- camera-controller.ts：独立的相机弧线插值，聚焦约 1.05 秒，进入约 .85 秒；减少动态效果时立即定位。
- planets.ts：唯一的颜色、地貌、位置、半径、数据分类与路由配置。
- /api/universe：真实本地统计，未调用抓取、分析和评分更新。统计失败显示未知，不显示伪造的零或随机更新。
- 选择状态存于 /?world=...，浏览器后退保留；五个内容世界复用 /explore?planet=...，分析继续使用 /analysis。
- /briefing：完整保留每日简报、手动更新、阅读工作台和历史入口。

## 当前背景：随视角变化的三维银河

- 新增 galaxy-background.ts：三维球形天空中的程序化银河带与暗尘带，加上分布在不同距离的简洁恒星点；没有外部图片或固定屏幕贴图。
- 天空与星点固定在场景空间中。旋转、缩放相机会改变实际看到的银河方向和星点位置，停止操作后背景保持稳定。
- 银河及恒星不受太阳系局部雾效影响，修复远景在手机视距下被雾完全覆盖的问题。相机远裁切面覆盖完整天空球。
- 桌面约 5000 个星点、手机约 2000 个；手机减少云雾噪声层数。天空与星点合计三次绘制，无外部资源下载。
- 优化视角阻尼；减少动态效果时关闭旋转惯性。星球增加轻微轴向倾斜；前景展开按实际时间平滑插值，低帧率时仍能及时完成。
- 新增银河构造/资源释放测试及背景截图回归：暂停太阳系后拖动空白天空，验证背景像素变化；停止拖动后像素保持稳定。
- 已查看 galaxy-overview.png、galaxy-rotated.png、galaxy-mobile.png、galaxy-reading.png、galaxy-reading-mobile.png，确认桌面、手机与阅读对比度。

## 小飞船与自由运动

- 移除上次添加的六条白色公转轨道线，保留实际公转和银河背景。
- 原创低多边形飞船，包含船身、机翼、座舱和小型推进器；整体最长尺寸为社区星球直径的三分之一，与星球共用场景光照。
- 默认自由巡航；可选择绕星飞行或前往星球，抵达后持续绕行。绕行参考目标星球当前坐标与朝向，跟随其公转。
- 手动驾驶支持镜头方向下的 W/S 前后、A/D 左右、Q/E 升降、Shift 加速，以及手机长按方向按钮。平滑加减速、转向和避障，提供重置位置按钮。
- 左下角飞船按钮及场景飞船标记打开紧凑控制面板，不新增页面，也不改变已有“返回全景才能切换板块”的规则。
- 暂停/减少动态效果停止飞船；切入阅读、失焦和页面隐藏时清空驾驶按键，表单输入和浏览器快捷键不被驾驶劫持。
- 飞船三维代码随场景按需加载，控制命令与类型单独放入轻量配置模块，无新增依赖或外部素材。
- 已验证模型尺寸、长时巡航边界及避障、连续多个移动目标的转场绕行、手动输入和释放后的减速，并查看 spacecraft-overview.png、spacecraft-controls.png。
